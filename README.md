 Cheetah – Python Voice Assistant

Cheetah is a simple Python-based voice assistant that listens for a wake word and performs basic tasks like opening websites, playing music, fetching weather updates, and responding with motivational quotes or fun facts.
This project is built to understand **speech recognition, text-to-speech, and command-based automation** using Python.



🚀 Features

- 🎤 Wake word activation (“cheetah”)
- 🌐 Open websites (Google, YouTube, Facebook, LinkedIn)
- 🎵 Play music using a custom music library
- ☁️ Get real-time weather updates
- 🧠 Tell random facts
- 💪 Give motivational quotes
- 🔊 Natural voice output using Google Text-to-Speech
- 🔁 Offline TTS fallback using pyttsx3
- ❌ Exit command to stop the assistant



🛠️ Technologies Used

- Python
- `speech_recognition`
- `gTTS`
- `pyttsx3`
- `pygame`
- `requests`
- `webbrowser`
